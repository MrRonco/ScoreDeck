ScoreDeck

Install in one click

Flash ScoreDeck to your Waveshare ESP32-S3-Touch-LCD-7 directly from this page — no IDE, no drivers to fight.

Requires desktop Chrome or Edge. Connect the board by USB-C first.

This browser can't flash over USB — use desktop Chrome or Edge.
  1. Plug the panel in over USB-C and hit Install above.
  2. If it reports "No serial data received", flip the board's UART slide switch and try again — it catches everyone once.
  3. When it reboots, the panel scans for Wi-Fi; type the password on the touch keyboard.
  4. Point it at your proxy (URL + token from install.sh), pick your leagues and favourites — on the panel or at http://scoredeck.local/.
Updating an existing panel?

This is a first-install image — it erases every setting, including the Wi-Fi password. To update a panel that's already set up, use OTA instead: curl -F "update=@scoredeck-ota.bin" http://scoredeck.local/update
